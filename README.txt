NUGGET vs MAX — TWIDDLE FINGERS VR

HOW TO PLAY
1. Upload this whole folder's contents to a GitHub repository.
2. In GitHub, open Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Choose the main branch and /(root), then Save.
5. Open the HTTPS GitHub Pages address on your Quest browser.
6. Choose Max Solo or Max vs Nugget, then press Start song.
7. Hit the four arrow buttons. On desktop use the arrow keys.
8. Press Enter VR to try immersive WebXR, then use a controller trigger on an arrow pad.

FILES
- index.html: game
- assets/nugget.webp and assets/max.webp: character pictures
- assets/max-solo.mp3: Max solo track
- assets/max-vs-nugget.mp3: Max vs Nugget track

NOTES
- Keep the assets folder beside index.html.
- Do not open index.html as a local file for VR. WebXR needs a secure HTTPS website.
- The game uses Three.js from jsDelivr, so an internet connection is needed.
- WebXR availability depends on the browser and headset permissions.
